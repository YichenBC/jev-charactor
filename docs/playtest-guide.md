# 雾港生活：第一轮试玩

目的：找到角色反应、交互后果和生活流程中的真实体验问题。建议 15–20 分钟，不需要负责论文评测，也不需要逐项测试。

入口：http://127.0.0.1:4317/ 。打开后若显示世界暂停，点“继续”。WASD/方向键移动，E 交谈或使用地点，B 背包。交谈时世界暂停；结束交谈后行动才会继续推进。

## 先自由生活

先吃饭、休息、挣钱，按自己觉得合理的方式探索。可以去晚风茶馆接外卖，完成配送后留意钱、订单和 NPC 反应是否变化。操作不清楚本身就是有效反馈，不必为了完成流程硬猜。

## 再挑一两个片段试试

- 问 NPC 有没有需要帮忙的事：他有没有提出具体工作、耗时和报酬？接受后是否真的做事并获得结果？
- 承诺稍后回来帮忙，离开再回来：是否还记得具体事情？回来后选项是否合理？若自愿尝试失约，留意后续是否有可理解的反应。
- 有不同食物时，试着赠送其中一种：选项是否清楚说明哪件物品？接受/拒绝后的背包与关系变化是否合理？
- 再次接触同一角色：是否还像完全初次见面？是否机械重复、无缘由变脸或透露不该知道的信息？

已经完成的工作不一定会再次出现；有些选项需要先发生对应事件。不能把选项没出现一律当 bug，请连同当时情境描述。

## 反馈格式

可通过仓库 issue 提交反馈，不要求上传存档。截图有帮助，但不是必需；提交前请检查其中是否含有个人信息或凭据。

```text
角色/地点：
当时在做什么：
我点了什么（记不清可以大概描述）：
我期待发生什么：
实际发生什么：
大约等了多久（若卡住）：
这个片段哪里自然/有趣，或哪里不合理：
```

最有价值的是 3 个片段：最不合理的一次、最像真实角色的一次、最想做却找不到选项的一次。不要为了反馈重复消耗同一存档里的物品或承诺。

结束时点击“保存”和“暂停”，避免挂着游戏让饥饿和订单继续变化。研发使用独立测试环境，不需要你重开档。此轮个人试玩仅用于开发改进，不直接算作论文盲评或测试集成绩。
